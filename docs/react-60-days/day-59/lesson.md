## Mental Model

Strong interview answer က term definition တစ်ခုသာမဟုတ်ဘဲ problem, chosen design, alternative, tradeoff နဲ့ repository example ကိုချိတ်ပြနိုင်ရမယ်။

## Implementation Tasks

1. Git diff/codebase ကိုcorrectness, types, UX, tests နဲ့security lens ဖြင့်review လုပ်ရန်
2. High-impact review findings ကိုseverity/effort အလိုက်စီရန်
3. React/TypeScript/architecture questions ကိုverbal or written ဖြေရန်
4. Bounded refactoring challenge တစ်ခုကိုtests/build မပျက်ဘဲလုပ်ရန်

Lesson ရောက်ချိန်မတိုင်မီ ဒီ planned implementation ကို မလုပ်ရသေးပါ။

## Guided Exercises

- Project decision သုံးခုကို STAR/decision format ဖြင့်ရှင်းပြရန်
- Code snippet တစ်ခုကိုlive review ပြီး issues/tradeoffs ပြောရန်

## Mini Challenges
